Solmere Air Service: eight missions over The Meridian Reach, a retro-futurist archipelago.
Fly the Wren IV "Sanderling" off the water at Solmere: run the mail to Sanderling Cay,
thread the Bellrock slalom, fly the Night Watch by instrument light alone, and finish the
Meridian Circuit. Three-dimensional flight model with stall, fuel and touchdown damage,
chase and cockpit cameras, a full HUD with minimap, six sky presets with weather and a
squadron radio. Keyboard and touch.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 in desktop Chrome
```
